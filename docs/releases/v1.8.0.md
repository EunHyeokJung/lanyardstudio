# LanyardStudio v1.8.0

[웹 앱 / Web app](https://lanyard-studio.com/) · [변경 이력 / Changelog](https://github.com/EunHyeokJung/lanyardstudio/blob/v1.8.0/CHANGELOG.md)

## 한국어

이 릴리즈는 이전 공개 릴리즈 v1.1.0 이후의 LanyardStudio 이름 변경, 프로젝트 관리, 디자인 도구, 데이터 편집, 모바일 개선을 포함합니다.

- **디자인:** 이미지·SVG, 글꼴 선택, 도형, QR 코드, 다중 선택·그룹, 요소 이름 변경, 복사·붙여넣기와 외부 이미지 붙여넣기
- **브랜드 바:** 여러 로고의 가로·세로 균등 배치, 개별 크롭·확대·순서 변경, 배경·여백·간격 설정. 정사각형 로고도 기본 비율을 유지하여 맞춤
- **데이터:** 변수 관리, 행 선택·일괄 삭제, 드래그 핸들 및 키보드 순서 변경, 실행 취소·다시 실행
- **출력:** A4 반접이 테이블 명패, 여러 페이지 인쇄 미리보기, 외곽선·재단선 및 실제 크기 PDF
- **모바일:** 상단 요소 도구, 태블릿 사이드 패널, 모바일 속성·출력 하단 패널, 내비게이션에 가려지지 않는 속성 스크롤
- **다국어:** UI, 랜딩 예시, 새 프로젝트와 샘플 명단에 8개 언어 적용. 기존 사용자 데이터는 언어 전환만으로 변경하지 않음
- **프로젝트:** 저장된 프로젝트 목록, 이름 변경, 브라우저 자동 저장, 이미지·명단 포함 JSON 백업·복원
- **배포:** 공식 주소 `lanyard-studio.com`, 이전 도메인의 다국어 이전 안내, 선택적 GA4, 설치형 PWA

### 다운로드

- 일반 사용: 웹 앱의 **앱 설치**로 PWA 설치
- 자체 호스팅: 아래 `lanyardstudio-v1.8.0-web.zip`을 다운로드하고 포함된 README에 따라 실행
- 소스 개발: 아래 GitHub의 **Source code** ZIP 또는 TAR.GZ 사용
- 무결성 확인: `SHA256SUMS`로 정적 빌드 ZIP 검사

정적 빌드는 운영자의 GA 측정 ID를 포함하지 않습니다. 네이티브 `.dmg`, `.exe`, `.apk`는 제공하지 않습니다. 브라우저나 사이트 주소가 바뀌면 기존 프로젝트가 자동 이동하지 않으므로 먼저 `.lanyardstudio.json`으로 백업하세요.

## English

This release consolidates the changes since the previous published v1.1.0: the LanyardStudio identity, project management, expanded design tools, roster editing, and responsive workflows.

- Text/font controls, images/SVG, shapes, QR codes, multi-select groups, layer names, element copy/paste, and external clipboard images.
- Horizontal/vertical brand bars with per-logo crop, zoom, reordering, spacing, padding, and backgrounds; proportional logo fitting by default.
- Roster selection, bulk deletion, pointer/keyboard row reordering, variables, and undo/redo.
- Folded A4 table tents, paginated print previews, outlines, crop marks, and true-size PDFs.
- Tablet side panels and mobile bottom sheets, including a fix for inspector controls hidden behind bottom navigation.
- Localized landing examples and sample rosters for Korean, English, Japanese, Simplified/Traditional Chinese, Spanish, French, and German. Existing project data is preserved when switching UI language.
- Saved-project lists, renaming, browser autosave, and JSON backup/restore.
- Official hosting at `lanyard-studio.com`, multilingual old-domain notice, optional GA4, and PWA installation.

Use the live app for PWA installation, the **web ZIP** for static hosting, or the **Source code** archives for development. The web ZIP contains no production-owner GA ID; verify it with `SHA256SUMS`. Native installers are not included. Export JSON backups before changing browser or site origin.

Full changes: https://github.com/EunHyeokJung/lanyardstudio/compare/v1.1.0...v1.8.0
